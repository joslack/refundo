You opened this page from a file. The frames cannot read the journeys file or the result tables. A frame cannot send the answer key to another frame. Use an HTTP server to open this page.

Each frame contains the renderer page. The test page sends the messages that LangSmith sends. In the trial pane, one frame gets the trial outputs. A second frame gets the answer key. Each message contains the trial inputs. In the comparison pane, one frame gets the answer key. Each other frame gets the outputs of one trial. Each message contains the example inputs. The test page sends each message 0, 100, 300, 700, 1500 and 3100 milliseconds after the frame loads. Drag the corner of a frame to change the frame size.
