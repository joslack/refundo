Tool journeys of the refund agents

Experiments

Each row is one experiment: one agent with one model and one effort. A step is the set of tool calls that the model made in one message. If the code of the agent made a tool call, that tool call is one step. The Steps column shows the median number of steps in a trial. The Tool calls column and the Failed tool calls column show the mean number in a trial. Each table column shows the percentage of trials that read the table one time or more. If a run_sql query named a table and did not fail, the trial read the table. If a trial called a tool that reads a table, the trial also read the table. The schema column counts list_tables and each run_sql query of information_schema or pg_catalog. Select a row to see that experiment below.

Read the tree from left to right. Each box is one branch. A branch is the sequence of steps from step 1 to the step in the box. The boxes on the right of a branch show the next steps. The branch with the most trials is first. A step is the set of tool calls that the model made in one message. The tree ignores the sequence of the tool calls in one message. The tree counts a repeated tool call one time. The length of the bar shows the number of trials on the branch. The green part shows the right trials. The red part shows the wrong trials. A branch with more trials has a taller box. If trials stop at a branch, the branch shows their number. The name of a run_sql tool call gives the tables that its query reads. If a name ends with a question mark, the database has no table with that name. If a tool call failed, its name ends with (failed). If the code of the agent made a tool call, its name ends with by code. Select a branch to see its trials.
